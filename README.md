# PlanQ Website

Static website for PlanQ. Plain HTML and CSS, no build step.

- `index.html` is the landing page.
- `img/` holds the app screenshots shown on the page.

Open `index.html` in a browser to preview it locally.

## Publishing

The site works with GitHub Pages as is: Settings → Pages → Deploy from a branch → `main`, folder `/ (root)`. `.nojekyll` keeps Pages from running Jekyll.

`docs/screenshots/` holds screenshots of the draft for review; they are not used by the page.
